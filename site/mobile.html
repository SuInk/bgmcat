手机与网页直接播放

把电脑当成你的私人追番媒体中心：在家走局域网千兆满速直连，出门走 Cloudflare Tunnel 加密穿透，躺在床上拿起手机就能点播本地与 Google Drive 番剧。

开启局域网手机直连

为了保证默认安全性，桌面版与服务版初始仅监听本机回环地址（127.0.0.1）。当你想用同一 Wi-Fi 或 Tailscale 组网下的手机、平板访问时，只需一键开启局域网监听，无需重启应用：

  1. 在电脑端打开「设置 → 安全与访问」，先确认已设置好管理员账号与密码（局域网与远程设备访问必须通过密码验证）。
  2. 打开「设置 → 远程与隧道 → 手机与局域网直连」，开启「允许局域网设备访问」开关并点击保存。
  3. 界面下方会立即列出当前电脑在局域网及虚拟组网（如 192.168.x.x、100.x.y.z）上的手机连接地址（桌面版固定端口为 39123，独立服务版默认为 3001），点击即可一键复制。
系统防火墙放行提示

首次在 Windows 或 macOS 开启局域网访问时，若系统弹出「是否允许 bgmcat 接受传入网络连接」，请勾选专用/家庭网络并点击允许，否则手机将无法连通电脑端口。

Cloudflare Tunnel 穿透

想在通勤路上、学校或公司等非家庭 Wi-Fi 环境下用手机看番，无需公网 IP 也不用折腾路由器端口转发，可直接在电脑端启用 Cloudflare Tunnel：

  • 安装 cloudflared：在运行猫追番的电脑上安装官方 cloudflared 命令行工具（macOS 可执行 brew install cloudflared，Windows 可执行 winget install Cloudflare.cloudflared）。
  • 快速临时隧道（零配置体验）：在「设置 → 远程与隧道」选择快速模式并启动，即可立即获得一个 https://xxx.trycloudflare.com 公网 HTTPS 地址，适合临时外出测试。
  • 固定域名命名隧道（推荐长期使用）：在 Cloudflare Zero Trust 控制台创建 Tunnel 并绑定你自己的二级域名（如 https://bgm.example.com），将 Tunnel Token 填入猫追番设置。重启电脑后地址永久不变，且具备异常断线自动重连能力。

Android 客户端使用

猫追番提供体积仅约 730 KB 的原生轻量 Android 客户端（bgmcat-android-*-universal.apk），专为移动流式看番与内外网无缝切换设计：

  1. 前往 下载中心 获取最新 .apk 安装到 Android 手机或平板。
  2. 首次打开进入「连接你的猫追番服务端」向导：
    • 主地址（局域网优先）：填入家里的电脑局域网地址，例如 http://192.168.1.25:39123；
    • 备用公网 / 穿透地址（可选）：填入你的 Cloudflare Tunnel 或 Tailscale 地址，例如 https://bgm.example.com。
  3. 毫秒级主备自动故障转移：每次打开 App 时，客户端会先以 2 秒超时探测局域网主地址——在家连着 Wi-Fi 时自动走局域网内网满速播放；一旦出门不在同一局域网，自动无缝切换到备用穿透地址连接，无需手动改配置。
  4. 原生观影体验：点击播放器全屏按钮时，App 自动切换重力感应横屏、隐藏系统状态栏与手势导航条，并保持屏幕常亮不息屏；登录会话 Cookie（30 天有效期）自动持久化在本地安全存储中。
  5. 随时切换多台服务器：在登录页底部或「设置 → 远程与隧道 → Android 客户端当前连接」中点击「切换服务器地址」，即可在家里桌面端与远程 NAS 之间一键切换。

iOS 与网页端 PWA

对于 iPhone、iPad 或其他电脑浏览器，无需安装额外客户端即可获得全屏原生级体验：

  • 浏览器直接访问：打开 Safari、Chrome 或 Edge，输入电脑端显示的局域网地址或公网 HTTPS 地址，输入管理员账号密码即可浏览片库、遥控电脑下载或直接点播视频。
  • 添加到主屏幕（iOS / iPadOS PWA）：在 Safari 打开你的猫追番地址 → 点击底部分享按钮 → 选择「添加到主屏幕」。从桌面图标启动后将隐藏浏览器地址栏，以独立全屏 App 形态运行，完美适配触控手势与安全区边距。
