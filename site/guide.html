使用文档 · 第一章

快速上手

从安装电脑桌面端开始，5 分钟打通「全库找番 → 自动下载 → 网盘归档 → 手机直连点播」完整工作流。

多端协同工作流

猫追番（Bangumi Cat）采用「一处运行核心服务、多端轻量直连播放」的协同架构，把繁重的 BT/HTTP 下载与网盘上传留在电脑或 NAS 上，手机与浏览器只负责按需流式点播：

  • 电脑桌面端 / 服务端（核心节点）：内置纯 Go 自研下载引擎（NativeEngine），无需外部安装 aria2。负责轮询 RSS 订阅、BT/HTTP 下载（支持未完成时边下边播），并在下载完成后自动分块上传至 Google Drive。
  • Google Drive（无限归档仓）：经过文件字节长度与 MD5 完整性双重校验后，可自动清理电脑本地文件，释放本机 SSD 空间，同时保留随时按需读取的云端媒体库。
  • Android 客户端与 iOS / 网页端（播放终端）：通过局域网 Wi-Fi 直连或 Cloudflare Tunnel 穿透连接你的电脑端，无需把几 GB 的视频先下载到手机，点击剧集即可通过 HTTP Range 流式播放本地或 Google Drive 视频。
隐私与所有权边界

猫追番不设中心化账号服务器。你的管理员密码哈希（PBKDF2-HMAC-SHA256）、订阅记录与 Google OAuth 凭据均保存在本机 SQLite 数据库中。

安装电脑桌面端

日常个人追番推荐直接安装 Electron 桌面版（bgmcat-desktop），内置 Go 后端与图形界面，双击即可启动并完成本机免密登录。到下载页获取安装包 →

操作系统 安装包格式 安装与首次启动说明
macOS（Apple Silicon / Intel） .dmg 打开镜像将 Bangumi Cat 拖入 Applications。首次打开未公证构建如遇拦截，可在「系统设置 → 隐私与安全性」点击仍要打开。
Windows 10 / 11（x64） .exe 运行安装向导（默认当前用户目录安装，无需管理员提权），完成后从桌面或开始菜单启动。
Linux（x64） .deb / .AppImage Ubuntu / Debian 执行 sudo apt install ./bgmcat-desktop-*.deb；AppImage 赋予执行权限（chmod +x）即可直接运行。
  • 零外部下载器依赖：顶部状态栏显示「内置引擎在线」即代表 HTTP 多连接与 BitTorrent 引擎已就绪；如果你已有主力 qBittorrent，也可在「设置 → 下载」切换为外部客户端。
  • 转码已内置：桌面安装包自带 ffmpeg，MKV / HEVC 10-bit 等浏览器放不了的视频会自动转码播放，不用另外安装。
  • 独立数据目录：桌面版数据默认保存在系统应用支持目录（macOS 为 ~/Library/Application Support/Bangumi Cat/server，Windows 为 %APPDATA%\Bangumi Cat\server），覆盖升级应用不会丢失数据。

番剧发现与全库筛选

左侧导航进入「发现番剧」，顶部单行工具栏整合了模式切换、分类筛选、关键词搜索、排序和视图切换：

  • 本季排期模式：按「全部 / 周一 … 周日」查看当季每日连载排期，自动高亮今天更新的番剧。
  • 全库索引模式：切换到「全库」后，可像视频站片库一样按多维度自由组合筛选往年经典番剧与剧场版：
    • 类型：TV、剧场版、OVA、Web 动画；
    • 地区与受众：日本、中国、欧美，以及 BL、GL、漫画改、轻小说改、原创等受众分类；
    • 年份与季度：支持具体年份（如 2026、2025…）、年代区间（90 年代、80 年代）搭配 1 月冬 / 4 月春 / 7 月夏 / 10 月秋季度；
    • 风格标签与排序：科幻、奇幻、恋爱、日常、悬疑、机战、音乐等题材标签，支持按排名、热度、评分、时间排序，滚动到底部自动加载下一页。
  • 详情抽屉一键操作：点击任意番剧卡片即可查看简介、分集进度，并并发检索蜜柑（Mikan）、Nyaa、ACG.RIP 资源，直接点击单集「立即下载」或「订阅连载」。

RSS 自动追番规则

对于正在连载的新番，使用「订阅配置」可实现每周更新后无人值守自动下载：

  1. 在番剧详情抽屉选择心仪的字幕组 RSS（如蜜柑番剧专属订阅链接），点击创建订阅；或在「订阅配置」页粘贴任意标准 RSS / Atom 地址。
  2. 设置包含关键词（例如 1080p, 简日）与排除关键词（例如 720p, 预告, 合集），精准过滤不需要的分辨率或版本。
  3. 开启同集自动择优去重：当同一集出现多个源或重发修正版时，系统会按你设定的字幕组与清晰度优先级挑选最优条目，避免同一集重复下载占满硬盘。
  4. 后台按设定的轮询间隔（默认 30 分钟）自动检查更新，新集入库后自动交由内置引擎下载，并在完成后衔接 Google Drive 归档流水线。
