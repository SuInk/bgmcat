服务端部署与运维

除了开箱即用的电脑桌面版，猫追番还可作为单二进制无头服务部署在 Linux / macOS / Windows 主机、家庭 NAS 或 Docker 容器中 24 小时常驻运行。

命令行一键安装

独立服务版将前端资源与纯 Go 下载引擎完整编译进单个可执行文件中（CGO_ENABLED=0，零外部 aria2 依赖），自动识别系统架构并完成 SHA256SUMS 校验：

curl -fsSL https://raw.githubusercontent.com/SuInk/bgmcat/main/scripts/install.sh | sh -s -- --start
irm https://raw.githubusercontent.com/SuInk/bgmcat/main/scripts/install.ps1 | iex
  • 默认安装位置：macOS / Linux 安装至 ~/.local/bin/bgmcat，默认数据目录为 ~/.anime-rss-go；Windows 安装至 %LOCALAPPDATA%\AnimeRSS\bin\bgmcat.exe。
  • 自定义监听与目录：例如在家庭 NAS 上监听局域网接口并指定数据盘路径： bgmcat --data /mnt/media/bgmcat-data --listen 0.0.0.0:3001
  • 平滑升级与回退备份：重新执行安装脚本会自动保留上一版二进制为 .previous 副本（Windows 升级前请先停止正在运行的进程）。

Docker 容器部署

项目内置多阶段 Dockerfile 与 docker-compose.yml，容器镜像已预装 ffmpeg 以开箱支持 MKV / HEVC 在线实时转码与内封字幕提取，并以非 root 用户安全运行：

Docker Compose 构建与常驻启动 
git clone https://github.com/SuInk/bgmcat.git
cd bgmcat
docker compose up -d --build
docker compose logs -f bgmcat
  • 默认映射宿主机 127.0.0.1:3001:3001，持久化数据与临时下载缓存在命名数据卷中隔离保存。
  • 如需通过 Nginx / Caddy 反向代理提供 HTTPS 公网访问，请将环境变量 ANIME_RSS_PUBLIC_URL 设置为你的实际外部域名（确保 Google Drive OAuth 回调地址准确匹配）。

账号密码与会话安全

所有远程与浏览器端访问均采用管理员账号 + 密码登录认证（桌面版窗口通过受控子进程管道自动完成本机会话握手，无需重复输入密码）：

  • 首次引导与加密存储：新环境首次启动时会在终端日志打印初始引导账号密码（或进入网页后引导修改）。密码经 210,000 轮 PBKDF2-HMAC-SHA256 加盐哈希存储，不保存明文。
  • 在线修改与一键踢下线：在「设置 → 安全与访问」修改管理员用户名或密码后，可立即使其他设备上的历史浏览器 / 手机 Cookie 会话全部失效。
  • 忘记密码命令行重置：若不慎遗忘管理员密码，可在宿主机终端使用相同的数据目录执行一键重置：
命令行重置管理员密码 
# 重置为指定新密码（省略密码值则自动生成高强度随机密码并输出到终端）
bgmcat --data ~/.anime-rss-go --reset-password "YourNewStrongPassword"

Diana MCP 与发布流水线

接入 Diana / AI 智能体（MCP）

控制台左侧「MCP」页面支持一键检测本机 Diana 环境并写入 --mcp-stdio 安全配置（保留原有其他 MCP 服务并自动生成备份），同时提供标准 POST /mcp 与 SSE 接口，让 AI 助手直接帮你查询当季新番、检查订阅状态、触发下载或查看网盘归档进度。

GitHub Actions 自动化构建与发布

仓库内置完整的 CI/CD 工作流，支持先在私有仓库（Private）跑通验证，随时平滑切换公开仓库（Public）：

  • 全平台构建与发布（.github/workflows/build.yml）：每次 Push / PR 自动运行前端类型检查、Go 竞态测试、原生 BT 本地节点传输测试与安装脚本测试；当推送匹配 internal/version/VERSION 的 vX.Y.Z 标签时，自动并行打包 5 平台服务端归档 + macOS/Windows/Linux 桌面安装包 + Android 签名 APK + Docker 镜像 + SHA256SUMS 并创建 GitHub Release。
  • Android 自定义签名密钥（可选）：若未配置仓库 Secrets，CI 会自动生成标准 PKCS12 密钥完成 V1/V2 签名以便直接安装测试；正式长期分发可在 GitHub Actions Secrets 配置 ANDROID_KEYSTORE_BASE64、ANDROID_KEYSTORE_PASSWORD、ANDROID_KEY_ALIAS、ANDROID_KEY_PASSWORD，保证跨版本无缝覆盖升级。
  • 官网与在线演示自动部署（.github/workflows/pages.yml）：main 分支更新时自动构建官网、文档中心与 /demo/ 纯前端交互演示，自动部署至 GitHub Pages。
