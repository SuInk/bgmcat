所有平台

大多数人只需要电脑上的桌面版。数据都存在自己的电脑里。

macOS

macOS 11 及以上

Apple 芯片（M1–M4） Intel 芯片

不知道是哪种芯片？点左上角苹果菜单 → 关于本机，看「芯片」一栏。

Windows

Windows 10 / 11，64 位

安装程序 .exe

首次运行如果弹出「Windows 已保护你的电脑」，点「更多信息」→「仍要运行」。

Linux

x86-64 桌面

AppImage（通用） .deb（Ubuntu / Debian）

AppImage 下载后加上可执行权限就能运行；Ubuntu / Debian 也可以装 .deb。

Android

Android 8.0 及以上

安装包 .apk

可以连接家里电脑上的猫追番，在手机上看已下载的番剧。使用说明

iPhone / iPad

不用安装

添加到主屏幕

用 Safari 打开电脑端的访问地址，点「分享」→「添加到主屏幕」。

服务器 / NAS

没有窗口，用浏览器访问

一条命令安装

适合 24 小时开机的迷你主机、NAS 或云服务器。

服务器 / NAS 一键安装

自动识别系统和架构、校验 SHA-256，装完直接启动。以后升级重跑同一条命令即可，数据不受影响。

      GitHub 发布页上文件很多，分别是什么？
      

        
文件名包含是什么谁需要

        
          
desktop-…-mac-arm64.dmg / mac-x64.dmgMac 桌面版安装包Mac 用户（同名 .zip 是同一个程序的压缩包，下 .dmg 就行）

          
desktop-…-win-x64.exeWindows 桌面版安装程序Windows 用户

          
desktop-…-linux-x86_64.AppImage / .debLinux 桌面版Linux 桌面用户

          
android-…-universal.apkAndroid 安装包Android 手机

          
bgmcat-linux-amd64.tar.gz 等服务器版程序（无窗口）一键安装脚本会自动下载，一般不用手动下

          
SHA256SUMS / latest.json校验值和版本清单脚本和自动更新使用

        
      

      
文件名带 -canary. 的是每次代码合并自动构建的测试版，可能不稳定，日常使用请装正式版。
