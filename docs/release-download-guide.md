
## 下载哪个文件

| 你的设备 | 下载 |
| --- | --- |
| Mac（Apple 芯片 M1–M4） | `bgmcat-desktop-{VERSION}-mac-arm64.dmg` |
| Mac（Intel 芯片） | `bgmcat-desktop-{VERSION}-mac-x64.dmg` |
| Windows 10 / 11 | `bgmcat-desktop-{VERSION}-win-x64.exe` |
| Linux 桌面 | `bgmcat-desktop-{VERSION}-linux-x86_64.AppImage`（Ubuntu / Debian 也可用 `.deb`） |
| Android 手机 | `bgmcat-android-{VERSION}-universal.apk` |
| 服务器 / NAS | 不用手动下载，运行一键安装命令即可，见 [安装文档](https://github.com/SuInk/bgmcat/blob/main/docs/install.md) |

其余文件：Mac 的 `.zip` 和 `.dmg` 是同一个程序，下一个就行，`bgmcat-<系统>-<架构>` 开头的压缩包是服务器版程序（一键脚本会自动下载），`SHA256SUMS` 和 `latest.json` 是校验值与版本清单。不确定的话，打开 [下载页](https://suink.github.io/bgmcat/download.html) 会自动推荐。
