# 猫追番 · Bangumi Cat v0.2.0

首个 Go 服务版本，将番剧订阅、下载与 Google Drive 归档整合进一个可执行文件。本文件是待发布说明，不表示版本已经上线。

## 新增功能

- 内置 HTTP 断点续传与 BitTorrent 下载，无需 aria2、gdirect 或 rclone。
- Google Drive OAuth、分块上传、大小和 MD5 校验、归档后可选清理及云端 Range 播放。
- Diana MCP 的本机 stdio 接入、配置保留、备份与诊断。
- 五平台完整包、SHA-256 校验、私有 Release 安装支持。

## 行为说明

- Vue 网页嵌入 Go 程序；没有 Electron 托盘或桌面自启动管理。
- 下载期间需要临时本地空间，转码需要可选 FFmpeg；真实 Google 上传需用户授权。
- 当前没有 WebUI 自动更新器，latest.json 是产物元数据。

## 升级与安装

源码安装：`sh scripts/build.sh`，然后运行 `./bin/bgmcat`。原生本地安装可用 `sh scripts/install-local.sh`。

私有 Release 发布后，在已克隆的项目中执行以下命令：

```sh
gh auth login
sh scripts/install.sh --repository SuInk/bgmcat --private --version v0.2.0
```

```powershell
gh auth login
.\scripts\install.ps1 -Repository SuInk/bgmcat -Private -Version v0.2.0
```

升级前停服并备份数据库，安装后保持原 `--data` 参数重启。旧 TypeScript 数据应先复制，再通过 `--import-legacy` 导入到空目录；未完成下载不会复用旧下载器的断点文件。

Docker 当前通过项目内 `docker compose up -d --build` 构建和升级，数据卷保留。手动下载完整包需校验 SHA256SUMS，解压运行 run.sh/run.bat。
