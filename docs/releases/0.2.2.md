# 猫追番 · Bangumi Cat v0.2.2

这一版主要是装好就能用：桌面安装包自带 FFmpeg，Android App 不再需要另开服务器，并新增 Canary 测试版通道。

## 本版新增

### 桌面安装包内置 FFmpeg

- macOS、Windows、Linux 桌面安装包都自带 `ffmpeg` / `ffprobe`。MKV、HEVC 10-bit 等浏览器放不了的视频会自动转码播放，内封字幕也能直接提取，不用再自己安装。
- 查找顺序：设置里填写的路径 → 安装包内置 → 系统 PATH → 常见安装目录（如 Homebrew 的 `/opt/homebrew/bin`）。从访达双击启动时，也能找到用 Homebrew 装的 FFmpeg。
- 内置的是 GPL 构建（转码用 libx264），许可全文随安装包附带，来源见 `THIRD_PARTY_NOTICES.md`。

### Android App 内置服务，打开即用

- App 里带了完整的猫追番后端，装好不用填任何地址就能进首页，在手机上直接订阅、下载、播放。
- 仍可切换为连接家里电脑或服务器（局域网地址 + Cloudflare Tunnel 备用地址自动切换）。
- 后端在前台服务里运行，通知栏可以一键退出。安卓版暂不带 FFmpeg，需要转码的视频会提示改用电脑端或服务器播放。

### 下载与云盘

- **按集数顺序下载和上传**：RSS 自动入队、批量添加和云盘转存都按 `01 → 02 → … → 10` 的顺序进行，不会再出现 `10` 排在 `2` 前面；边下边播仍然可以插队。
- **下载目录分组**：默认按「番剧名 / 字幕组」分层，也可选只按番剧、只按字幕组或不分组。云盘里保持同样的目录结构，本地清理后不再残留空文件夹。
- **云盘外挂字幕**：提取出的 `.ass` / `.vtt` 字幕会随视频一起上传到云盘同目录，播放云盘里的 MKV 能立刻加载字幕。

### 界面

- 下载管理：统一海报网格，显示 Bangumi 剧集名称；行操作精简为「播放 + 更多」；左右侧栏可以拖动调宽，双击恢复默认。
- 清理缓存、删除备份、断开云盘、重置令牌、移除设备、退出登录等操作增加了二次确认。
- 数据源支持「测试全部」和拖动排序；订阅卡片用标签展示规则（字幕组、画质、语言、范围、去重）。
- 修复下拉菜单在部分设置分组和弹窗里被遮挡的问题。

### Canary 测试版与更新通道

- 每次代码合并后自动发布一个 Canary 测试版（如 `v0.2.3-canary.1`），全平台安装包齐全，适合想抢先试用新功能的人。
- 点侧栏底部的版本号打开「版本与更新」，可以把更新通道切到 Canary，检查更新时会提示这类版本；默认的稳定版通道只看正式版。
- 一键安装脚本和官网下载页始终只提供正式版。

### 官网与文档

- 下载页会按你的设备直接推荐一个安装包（Mac 会区分 Apple 芯片和 Intel），每个 Release 的说明末尾附有「下载哪个文件」对照表。
- 在线演示修复了地址跳出演示目录、刷新 404 和点播放黑屏的问题。
- Windows 一键安装命令现在也会在装完后直接启动，和 Linux / macOS 一致。

## 安装与升级

- **电脑**：到 [下载页](https://suink.github.io/bgmcat/download.html) 下载桌面版，覆盖安装即可，数据保持不变。
- **Android**：下载 `bgmcat-android-0.2.2-universal.apk` 覆盖安装。
- **服务器 / NAS**：重跑一键安装命令即可升级（会自动保留上一版为 `.previous`）：

```sh
curl -fsSL https://raw.githubusercontent.com/SuInk/bgmcat/main/scripts/install.sh | sh -s -- --start
```

```powershell
irm https://raw.githubusercontent.com/SuInk/bgmcat/main/scripts/install.ps1 | iex
```

## 已知边界

- 桌面安装包仍未做 Apple 公证和 Windows 代码签名，首次打开如遇系统拦截：macOS 在「系统设置 → 隐私与安全性」点「仍要打开」，Windows 点「更多信息 → 仍要运行」。
- 安卓版暂不支持 FFmpeg 转码。
- 不提供 iOS 安装包，iPhone / iPad 请用 Safari 打开电脑端地址并「添加到主屏幕」。
