# 猫追番 · Bangumi Cat v0.2.1

猫追番（Bangumi Cat）首个正式发布版本，也是首个多端协同正式架构版本：**电脑桌面端 / 服务端自动追番并归档至 Google Drive，手机 Android 客户端与网页端随时直连流式点播**。

## 本版新增：边下边播

- **资源行一键边下边播**：番剧详情页每条字幕组资源新增「▶ 边下边播」，没加入的自动加入下载；已加入的也能直接点，已下完显示「播放」。
- **下载管理里随时开播**：「正在缓存」列表中排队、暂停或出错的 BT 任务显示描边播放键，展开的剧集 / 版本面板同样可用；点了任务立即开始（不占普通并发名额），开头片段校验通过后自动打开播放页。
- **拖动进度更快**：拖到还没下载的位置时，优先下载目标附近的片段，预读随连续播放逐步放大；本地 256 KB/s 限速实测拖到 70 秒恢复播放由约 48 秒缩短到约 16 秒。
- **手机端修复**：窄屏下顶栏不再把整页撑宽，资源行的「下载 / 边下边播」按钮不会再被挤出屏幕。
- 边下边播需使用内置下载引擎，仅支持磁力 / 种子任务；直链任务与 aria2 / qBittorrent / Transmission 下载完成后播放。

## 核心亮点

- **纯 Go 自研下载引擎（零 `aria2` 依赖）**：内置 `NativeEngine` 原生提供 HTTP 多连接断点续传与 BitTorrent / Magnet / DHT / PEX 下载，支持顺序分片边下边播；桌面端、服务端与 Docker 均开箱即用，无需再安装外部 `aria2c`。
- **本季排期 + 全库多维筛选**：首页新增「本季 / 全库」单行紧凑工具栏，支持按类型（TV / 剧场版 / OVA / Web）、地区、受众、年份与年代、季度、风格标签及排名/热度/评分/时间自由组合检索全部番剧，滚动触底自动加载。
- **Google Drive 自动归档与空间释放**：8 MiB 分块断点上传，严格核对云端文件字节数与 `md5Checksum` 后可安全清理电脑本地副本；支持云端 HTTP Range 原画直连播放、可选 `ffmpeg` 实时窗口转码字幕提取，以及独立 TLS SNI 的 Google Drive IP 直连测速。
- **电脑桌面端一键局域网共享 + 原生 Android 客户端**：
  - 电脑端「设置 → 远程与隧道」新增 **允许局域网设备访问**，无需重启即可动态监听局域网 / Tailscale 地址并生成一键复制链接；
  - 新增体积仅约 730 KB 的原生 **Android 客户端（`bgmcat-android-0.2.1-universal.apk`）**，支持「局域网主地址 + Cloudflare Tunnel 穿透备用地址」毫秒级自动故障转移、视频横屏沉浸全屏与屏幕常亮；iOS 与浏览器支持全屏 PWA。
- **管理员账号密码安全认证**：采用 210,000 轮 `PBKDF2-HMAC-SHA256` 账号密码会话认证，支持在线修改密码踢下线及命令行 `--reset-password` 一键重置；桌面端自有窗口自动完成本机免密握手。
- **Diana MCP 与全平台交付**：支持本机 Diana `--mcp-stdio` 一键接入；统一交付 macOS / Windows / Linux 桌面安装包、Android APK、五平台独立服务包与 `SHA256SUMS`。

## 安装与升级指南

### 1. 电脑桌面端与 Android 手机端（推荐）

从本 Release 资产中下载对应系统安装包，核对 `SHA256SUMS` 后安装：

- **电脑端（自动下载 + 网盘归档）**：macOS 下载 `.dmg`（Apple Silicon 选 `mac-arm64`，Intel 选 `mac-x64`），Windows 下载 `win-x64.exe`，Linux 下载 `.deb` 或 `.AppImage`。
- **手机端（直连流式播放）**：Android 手机下载 `bgmcat-android-0.2.1-universal.apk`；iPhone / iPad 直接用 Safari 打开电脑端局域网或穿透地址并「添加到主屏幕」。

### 2. 独立服务版命令行一键安装

macOS / Linux：

```sh
curl -fsSL https://raw.githubusercontent.com/SuInk/bgmcat/main/scripts/install.sh | sh -s -- --version v0.2.1 --start
```

Windows PowerShell：

```powershell
irm https://raw.githubusercontent.com/SuInk/bgmcat/main/scripts/install.ps1 | iex
```

Docker 部署执行 `docker compose up -d --build` 即可。早期 TypeScript 旧版数据请先备份并通过 `--import-legacy` 导入全新的空数据目录，详见 `docs/usage.md`。

## 行为说明与已知边界

- 本版不提供 iOS 安装包（`.ipa`）：iPhone / iPad 请用 Safari 打开电脑端地址并「添加到主屏幕」。
- 桌面安装包当前未绑定付费 Apple Developer ID 公证或 Windows EV 代码签名证书，首次启动如遇系统安全提示请按文档指引放行。
- 下载阶段需要本机临时磁盘空间，全部文件通过 Google Drive 大小与 MD5 校验后方可触发自动本地清理；非浏览器原生编码（如 MKV / HEVC 10-bit）实时转码需本机装有可选 `ffmpeg`（Docker 镜像已内置）。
